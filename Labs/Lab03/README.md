# Lab 03 – Working with Git History, Stashing, and Reverting Commits

## Objective

This lab focuses on advanced Git operations, including conflict resolution, commit history management, stashing, resetting, reverting, and GitHub workflows.

1. Handling Local and Remote Commit Conflicts
2. Creating and Resolving Merge Conflicts

4. Using git stash
5. Checking Out a Specific Commit
6. Soft and Hard Reset
7. Amending the Last Commit
8. Reverting a Commit
9. Force Push
10. Running Gitea with Docker Compose in GitHub Codespaces
11. Creating a GitHub Pages Portfolio
